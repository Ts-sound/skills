# md2talk-video sample talk

用于冒烟测试的样例：两章、四页，含 `[pause]` 停顿标记和一页故意缺演讲稿。

## 第一章 问题与目标

### P1 为什么讲这件事

> 大家好，今天聊一个很实际的问题：为什么你写的文档，讲出来总像念说明书。
> 先看一个场景，[pause] 你花了三天做的方案，汇报时十分钟就被人问住了。

- 文档写得好 ≠ 讲得好
- 听众只记得住三件事

### P2 我们要什么

> 这一节先说目标。我们要的不是更漂亮的 PPT，而是让每一页都有话说、每句话都有落点。

- 每页一个观点
- 每页一段可朗读的稿子
- 视频能直接发出去

## 第二章 做法

### P3 三步流水线

> 做法分三步：先把大纲拆成一页页的演讲稿，再把稿子变成配音和字幕，最后让画面跟着声音走。
> [pause] 顺序不能反，先有声音，画面才有节奏。

- 拆页：Markdown 章节 / 子页 / 演讲稿
- 出声：TTS + 逐页字幕
- 成片：渲染 + 混流 + 拼接

### P4 落地检查

- 阶段产物要能单独审
- 断点续跑要可靠
