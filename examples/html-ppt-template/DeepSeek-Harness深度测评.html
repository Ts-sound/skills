设计哲学 · 核心解读
  • 基于 Kora 框架：一切皆是插件，包括驱动 Agent 的 ReAct 循环本身。
  • 五大接插件：模型、工具、策略、存储、上下文管理均可定制。
  • 官方界面可替换：用户无需使用默认 UI，写插件即可接入自己的界面。
  • 一切外部组件：甚至可以把整个 Runner 逻辑替换成自定义实现。
