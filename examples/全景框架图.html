日本历史宏观走向：数据 → 来源 → 工具 → 分析方法
按"你要什么指标 → 去哪拿最权威 → 用什么代码拉 → 怎么观察历史"四层推进
① 你要的指标
GDP
总量、增速、人均
人口
总人口、年龄结构
各行业指标
分行业GDP、工业产出、服务业
物价 / 利率 / 就业
CPI、政策利率、失业率、工资
② 权威数据源（最权威打底 + 聚合省事）
日本官方（最细、最权威）
· GDP → 内閣府（国民経済計算 SNA）
· 人口 → 総務省統計局（国勢調査・人口推計）
· 行业产出 → 経済産業省（鉱工業生産指数）
· 物价/利率/就业 → 日本銀行・総務省・厚労省
国际聚合（多国多年、可编程）
· FRED（美联储）日本系列 3000+
· World Bank WDI（GDP/人口/行业占比）
· OECD / IMF（跨经济体可比）
③ Python 获取方式（推荐组合）
pandas-datareader
直连 FRED，拉 GDP/CPI/失业/IIP
wbgapi / World Bank API
WDI 人口、GDP、行业占比
yfinance
日经225等股指做联动
e-Stat API（可选）
日本官方细项，注册拿 key
④ 观察"历史宏观走向"的方法
A. 长时序 + 关键断点
1980繁荣 → 1991泡沫破裂 → 1997亚洲金融 → 2008雷曼 → 2013安倍经济学 → 2020疫情。对数坐标看长期趋势。
B. 行业结构变迁
制造业占 GDP 比重下降、服务业上升、老龄化 → 观察产业与人口结构长期迁移。
C. 宏观 × 股指联动
把 GDP/CPI/利率与日经225叠加，看宏观周期如何驱动股市、通胀与泡沫。
